# EyOD – TP01 Arreglos / Listas (estilo ICPC, Java)

Un problema por carpeta: `NN_Clase/Clase.java` (version optimizada), `NN_Clase/ClaseFuerzaBruta.java` (version fuerza bruta), `casoN.txt` (entrada) y `salidaN.txt` (salida esperada).

Cada clase sigue la plantilla ICPC (`leerDatos()`, `resuelve()`, `main`) y usa POO:
la clase principal maneja la entrada/salida (atributos privados) y la clase interna `Solucion` contiene el algoritmo.

Probar uno:   `javac 01_DosSumas/DosSumas.java && java -cp 01_DosSumas DosSumas < 01_DosSumas/caso1.txt`
Probar todos (ambas versiones): `./probar.sh`
Ambas versiones usan los mismos `casoN.txt` / `salidaN.txt`.
